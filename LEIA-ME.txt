 Esse é meu portfólio pessoal, criado para mostrar alguns projetos que desenvolvi durante o curso de Engenharia de Software na UNINGÁ.

 O site tem informações sobre mim, as tecnologias que estou estudando e meus projetos.

Tecnologias utilizadas

- HTML: estrutura do site.
- CSS: aparência, cores e responsividade.
- JavaScript: interações, temas e funcionamento dos projetos.
- C++: programas de terminal.
- GitHub Pages: hospedagem do site.

Projetos

 O portfólio conta com 6 projetos, separados em duas categorias:

Projetos em HTML
- Loja Sonical
- TechShop
- PokeSearch

Projetos em C++
- Banco Tche Tche
- Campeonato Brasileiro
- Conversor de Moedas

Como utilizei o iframe: O iframe foi usado para abrir os projetos HTML dentro do próprio portfólio, sem precisar abrir outra aba. Quando clicamos em "Abrir projeto", o JavaScript pega o caminho do projeto escolhido e coloca no `src` do iframe, mostrando o site em uma janela que pode ser fechada. Já os projetos em C++ possuem uma simulação de terminal feita com JavaScript, pois  GitHub Pages não executa programas C++ como os HTML.
