Experimente o programa

Este terminal reproduz no navegador o fluxo de interação do programa original. Digite as opções e os valores solicitados, como faria ao executar o código no terminal.

Como interagir:

  • Digite sua resposta no campo abaixo do terminal.
  • Pressione Enter ou clique em Enviar.
  • Use “Reiniciar execução” para começar novamente.
